llama.cpp b12287 发布：CUDA BF16 小批次矩阵性能优化

7.0

llama.cpp 发布了 b12287 版本，核心改进是针对 CUDA BF16 小批次矩阵运算的性能优化。该版本引入 MMVF 内核替代原有的 MMF 内核，以解决在小批次（batch sizes 2..8）下，行数较少的 BF16 矩阵（如 qwen4exp 的 320 行投影）导致大部分流多处理器（SM）空闲的问题。MMVF 采用每行一个 block 的执行方式，在 K 维度足够长时表现更优。

github · github-actions[bot] · 11月11日 18:15

背景与影响

「技术背景与优化原理」 在 llama.cpp 的 CUDA 实现中，MMF（Matrix-Matrix-Float）内核通常每 block 处理 32 行矩阵。当矩阵行数较少时，分配的 block 数量少，导致 GPU 上大量的 SM 处于空闲状态，利用率低下。MMVF（Matrix-Matrix-Vector-Float）内核通过每行运行一个 block 的方式，提高了在小行矩阵场景下的 SM 利用率，从而提升整体推理性能。

「对用户的实际影响」 对于使用 CUDA 后端运行包含小行 BF16 矩阵模型（如 qwen4exp 系列）的用户，升级到 b12287 版本后，在小批次推理场景下将获得更好的 GPU 利用率和推理性能。优化策略会根据 GPU 的 SM 数量、矩阵维度自动选择 MMVF 或 MMF 内核，无需用户手动干预。
